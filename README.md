# Эротическое кино 18+ для Lampa

Плагин добавляет в Lampa отдельный каталог эротических фильмов и поиск. Результаты берутся из TMDB и открываются в стандартной карточке фильма Lampa.

Это обеспечивает совместимость с уже установленными плагинами воспроизведения: Lumio, Alpaca и другие источники получают обычную карточку с TMDB ID, названием, годом и типом `movie`, после чего показывают собственный выбор источников.

## Возможности

- каталог по актуальным эротическим меткам TMDB, отсортированный по рейтингу;
- поиск фильма по названию прямо на экране каталога;
- фильтр по году выпуска;
- стандартные постеры, описания, год и TMDB ID;
- переход в штатный экран фильма Lampa;
- совместимость с внешними плагинами источников;
- подтверждение возраста 18+.

Плагин сам не хранит видео, не раздаёт файлы и не подменяет установленные источники воспроизведения.

## Отдельный каталог «Полное 18+»

Репозиторий также содержит `adult18.js` и backend `server.js`. Каталог **Полное 18+** получает
публичные NSFW-карточки PeerTube и использует только опубликованные самим сервером прямые HLS/MP4-потоки.

Карточка фильма показывает год, автора, теги, длительность и описание, когда эти данные заполнены
источником. Над каталогом доступны поиск и выпадающие фильтры **Год**, **Жанр** и **Качество**; настоящий год фильма
извлекается из названия и описания, а не из даты загрузки на PeerTube.

Экран выбранного фильма выполнен как отдельная Activity Lampa с постером, полными сведениями,
описанием и кнопкой **Смотреть**. Актуальный JavaScript отдаётся самим Render backend через `/plugin.js`
с отключённым кэшем, чтобы телевизор не оставался на старой версии CDN.

Для Render используется тип **Web Service** со следующими параметрами:

- Build Command: пусто;
- Start Command: `node server.js`;
- Health Check Path: `/health`;
- `TPDB_API_TOKEN`: секретный токен ThePornDB;
- `TPDB_API_BASE`: `https://api.theporndb.net`.

Токен ThePornDB нельзя добавлять в файлы репозитория или в URL плагина.

Адрес backend: `https://lampa-kakm.onrender.com`.

## Установка

Добавьте в **Настройки → Расширения → Добавить плагин**:

```text
https://raw.githack.com/bodexbg-a11y/lampa/main/e32.js
```

После установки перезапустите Lampa. В главном меню появится пункт **Эротика 18+**. Нажатие сразу открывает фильмы; над сеткой находятся нативные selector-кнопки **Поиск** и **Год**.

## Как работает воспроизведение

1. Пользователь выбирает фильм в каталоге.
2. Плагин открывает стандартную карточку Lampa с источником `tmdb`.
3. Lumio, Alpaca или другой установленный плагин добавляет свою кнопку или список источников.
4. Воспроизведение выполняет выбранный внешний плагин.
